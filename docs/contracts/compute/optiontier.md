# Candidate tiers (`internal/compute/optiontier`)

Source: `docs/design/candidates-tiers.md`, Decisions 2 to 8 and entry 2. The package implements `optiontierapi.Tierer`. Every number is decimal text; it has no float, no clock and no I/O; an empty string is "no value".

**The tier rules, word for word.** A row is green, "fits" (never "recommended"), when all hold: the buy price is set (above 0); break-even (strike minus bid) is at most the buy price; the put is out of the money (strike not above spot, so an at-the-money put is not in the money); |delta| is at most `Params.DeltaMax` (no lower bound; |delta| below `ThinDelta` stays green and carries the note `thin_premium`); and, when `Result.CashBuilt`, at least one known alias has free cash of at least strike times multiplier. A row is amber, "check", when the first three hold and one or more look-at badges are present. A row is grey when a hard condition fails or cannot be judged. An empty or unreadable delta is the look-at badge `delta_unknown`, so such a row cannot be green.

**Grey reasons and their order.** One reason per row, in this order of precedence: `no_buy_price` (empty or not above 0), `no_spot`, `in_the_money` (strike above spot), `no_bid` (empty or not above 0), `above_buy_price`, `bad_input` (a text that is not a number, the mark `unreadable_gates`, or an `optionevidenceapi.ErrBadInput` of the evaluator, found with `errors.Is`). Any other evaluator error is returned by `Judge`. No row is dropped: `Verdicts` has one entry per row in input order and `Order` holds every key once (fits, check, then grey by reason, then expiry, strike, key). Inside fits and check the order is `MarginPct` descending, `YieldPct` descending, then DTE, strike and key ascending; a row with no figure goes last. `Place` is the 1-based position inside the tier. The evaluator is not called for a row grey for `no_buy_price`, `no_spot` or `no_bid`.

**Badges.** Look-at, in this fixed order: `no_open_interest` (mark, or quote reason), `low_open_interest`, `one_sided_quote` (quote reasons `no_quote`, `no_bid`, `no_ask`, `small_bid_size`), `wide_quote` (`wide_spread`), `stale_quote` (quote reason `delayed_data`, events reason `stale_chain`), `earnings_before_expiry` (events reason), `cash_short`, `delta_above_bound`, `delta_unknown`. Info, never demoting: `earnings_unconfirmed` (mark or events reason), `earnings_beyond_horizon` (`beyond_horizon`), `earnings_unknown` (`no_earnings`, `stale_earnings`, `earnings_unsupported`, `earnings_error`), `cash_unknown`. Note: `thin_premium`. `cash_short`, `delta_*` and the note are written only for a row that is not grey. A stored info mark carried by every row is returned once in `Result.Common` and removed from each row's `Infos`; `cash_unknown` is per row and never folded. A look-at badge is never folded. `Result.Kept` lists, in a fixed order (the grey reasons, then the look-at badges), each condition with N rows and `Every` true when N equals the rows read.

**Cash.** Per alias, `free` is `Cash` minus the sum of strike times multiplier times |quantity| over the positions with `SecType` "OPT", `Right` "put", a negative `Quantity` and `Currency` "USD". An alias is unknown with `Why` `no_cash` (the cash is empty or not a number; also a short put whose strike or multiplier is not a number), `not_usd` (currency other than USD), `stale_cash` (`AgeDays` above `MaxCashAgeDays`; the caller counts the days, the package does no date arithmetic) or `other_currency` (a short put in another currency), tried in that order. `CashBuilt` is true when some alias is known. A cell is `fits` when `Free` is at least strike times multiplier, `short` otherwise, `unknown` with a `Why`; `FitAlias` is the first alias in input order that fits. With `CashBuilt` false cash is a mark: no row gets `cash_short` and each row gets the info `cash_unknown`.

**Figures and units.** Money is the decimal result as text; a percent is at four decimals (half away from zero). `MarginPct` and `BelowBuy` are the evaluator's `BelowBuyPct` and `BelowBuy`; `Moves` is its `BreakEvenInSigmas`; `BelowSpotPct` is (spot minus break-even) / spot times 100; `PerContract` is bid times multiplier (100 when the multiplier is empty); `Intrinsic` is max(0, strike minus spot); `TimeValue` is bid minus intrinsic; `YieldPct` is time value / strike times `DaysInYear` / DTE times 100, of the time value only. A time value below zero is not given: when the bid is above 0 and below the intrinsic value, `TimeValue` and `YieldPct` are empty and the reason is `bid_below_intrinsic`. An empty figure has a code in `Verdict.Why` by figure id (`margin`, `below_spot`, `moves`, `per_contract`, `time_value`, `yield`): `no_iv` for `moves`, `bid_below_intrinsic` for `time_value` and `yield`, `zero_dte` for a yield with no days, otherwise the grey reason.

**Trial values.** `DefaultParams` gives `DeltaMax` "0.3", `ThinDelta` "0.15", `MaxCashAgeDays` 3 and `DaysInYear` 365; all four are trial values the owner sets after seeing the page. An empty or unreadable number of the input `Params` is replaced by its default, and `Result.Params` echoes the numbers used.

**The evaluator is injected.** `New(ev optionevidenceapi.Evaluator)` takes the one evaluator of margin and moves; the package computes no second formula for them and imports neither `optionevidence`, `bsm` nor `internal/strategy`.

**Company blocks.** `Result.Blocks` has one `CompanyBlock` per company. The state is a total rule over the company's rows, first match wins: a fits or check row inside the band and shown gives `sellable`; else any fits or check row gives `out_band`; else (all rows grey) any `no_buy_price` row gives `no_buy_price`; else `above_buy` when at least one row is `above_buy_price` and no row is `no_spot` or `bad_input`; else any `no_spot` or `no_bid` row gives `no_quote`; else `blocked`. The band, on exact decimals, is out of the money by (spot minus strike) over spot from `Params.BandOTMMinPct` to `Params.BandOTMMaxPct` percent (default "5" and "15"), |delta| from `Params.BandDeltaMin` (default "0.15") to `Params.DeltaMax`, and open interest present; at most `Params.PerCompany` (default 3) rows are shown. Shown rows are sorted by `YieldPct` descending (empty last), then DTE, strike and key ascending; `Best` is the `YieldPct` of the first. Every row that is not shown is in `Folded` with exactly one fold reason (its grey reason, else the first failing band code in the order `no_open_interest`, `otm_low`, `otm_high`, `no_delta`, `delta_out`, else `over_cap`), so `len(Shown)` plus the sum of `Why` counts is the company's rows. `Blocks` is never nil. The existing `Order`, `Place` and `Companies` do not change.
