# fx_refresh

## fx_refresh

- `fxrefresh.NewFxRefreshFunc` (implemented by `internal/jobs/fxrefresh.New`; design `docs/design/market-bars.md`, Decision 9): `func(broker.Broker, broker.HistoryClient, bar.FxRateWriter, bar.FxRateReader, clock.Clock) (contracts.Job, error)`.
- Id `fx_refresh`; one key `{obs.fx_rate, USDJPY}`; schedule `XNYS`, `session_close`, offset 15 minutes, `run_bound` 10 minutes; `job.toml` also holds `duration_days` (5).
- `Run` first asserts the writer to `bar.FxRateUpserter` (design `docs/design/data-repair-fx.md`, Decisions 4, 6, 8); a writer without `UpsertFxRates` (no bar DSN) makes `Run` return a Retryable error naming the missing bar store, before any broker call, and never falls back to `InsertFxRates`. It resolves the USD.JPY cash contract once through `Broker.ResolveContract` (sec type `CASH`, symbol `USD`, exchange `IDEALPRO`, currency `JPY`; not listed is Permanent) and asks `MIDPOINT` for 5 days with `End` set to the day when the day is before the UTC date of the clock and empty otherwise. Bars whose day is after the day are dropped; the rest are upserted by key in one `UpsertFxRates` call with `writtenBy` `fx_refresh:<day>` (`rate` is the close text, `source` `ibkr_midpoint`). A differing stored rate is replaced, an equal one (numerically) is untouched, and no old value is kept. The job no longer reads the stored days. An empty answer replaces nothing, writes nothing, returns zero rows and fabricates nothing; no default rate exists in the package. A history or store error is Retryable unless it is already typed; a close that is not a positive decimal and a bar day that does not parse are Permanent.
