# pages contract

## Responsibility

Build the view model of a page from stored values and serve it inside a static page. `macro_rates.Build` reads the series Reader and emits `page.macro_rates.v3` JSON; `embed.Handler` writes that JSON into the built page at serve time and `embed.Assets` serves the bundle files. Pages make no request: the one place a page reads its data from is `<script id="vm" type="application/json">`.

## Interface

- `pages.Meta{Name, Schema}`: `Schema` is informational; no code reads it and it is not the JSON field `schema`.
- `pages.Builder`: `func(ctx, store.SeriesReader, contracts.Day, generatedAt time.Time) ([]byte, error)`.
- `pages.Page{Meta, Build}`.
- `macro_rates.Page()` returns `Meta{macro_rates, page.macro_rates.v3}` with the package `Build`.
- `underlyings.Page()` returns `Meta{underlyings, page.underlyings.v1}`; its Builder builds the read-only page of no rows for the given day and instant.
- `underlyings.Build(in Input) ([]byte, error)` (new): JSON of `contracts/schemas/page.underlyings.v1.json` from the stored rows, the held symbols, the history, the form token, the confirm block, the notice, the clock value and the owner zone; `Follows` is the one rule of "followed by"; texts in English, written by `text.go`; reads no store and no clock.
- `price_lines_page.Page()` (new) returns `Meta{price_lines_page, page.price_lines_page.v1}`; its Builder builds the read-only page of no reader (one `no_reader` gap, no rows).
- `price_lines_page.Build(in Input) ([]byte, error)` (new): JSON of `contracts/schemas/page.price_lines_page.v1.json` from the underlying rows, the held stock symbols, `Reader` (false: the `no_reader` gap, `run_status` `partial`, no rows), the form token (nil: the inert constant token), the saved and error texts and the clock value; `rows` are the rows with a `BuyPrice` sorted by market then symbol, `unset` the held rows with none that are not retired. It reads no store and no clock.
- `job_console.Build(ctx, r jobrequest.Reader, generatedAt time.Time, form *Form, selected int64, jobs []JobInfo) ([]byte, error)` (new): JSON of `contracts/schemas/page.job_console.v1.json` from the newest 20 requests of the reader (nil gives the gap `job_requests_unavailable`, and so does a reader error), the form token (nil: `form` null), the selected request id (0 for none; listed even when older than the 20, an unknown id gives the gap `no_such_request`) and the job table of the caller (`JobInfo`: `ID`, `Kind`, `Zone`, `Note`, `WhyCode`, `WhyText`, `NeedsText`, `ForceOK`, `ForceWhy`; `today` of a job is the date of `generatedAt` in its `Zone`). Each stored key line maps to one of nine outcomes and a reason, and a `rerun` line is never `produced`; the request-level text is a function of `(state, reason, hold, withdrawal)`; a `done` request with no `produced` line reads "nothing was produced" in `sentence`; `refresh_seconds` is 5 while a shown request is `queued` or `running`. Texts in English, written by `text.go`; imports no `cmd/ot` and no runner package; reads no clock.
- `flex_import.Page()` returns `Meta{flex_import, page.flex_import.v1}`; its Builder builds the read-only page (form null, one `no_reader` gap, no files, no recent records).
- `flex_import.Build(in Input) ([]byte, error)` (new): JSON of `contracts/schemas/page.flex_import.v1.json` from the form fields (nil for off), the gaps, the file results and the recent items, all plain values; imports no store row type and no jobs package. The file name is cut to its base name and at most 80 runes; the file status is the first that applies of `failed`, `stored`, `present`, `unconfigured`, `nothing_found`; the sentence of a status and of a reason comes from a closed table (a stored file reads "Stored: N new rows", N the sum of `rows_new` of its aliases); `scope_note` is one constant; an unknown status or reason is an error; texts in English; reads no store and no clock.
- `ops_today_page.Build(runs []runview.Row, reasons []runview.Reason, now time.Time) ([]byte, error)` (new): JSON of `contracts/schemas/page.ops_today_page.v1.json`. Lists, per (dataset, key), the newest finished run only (a running row is skipped) of the datasets `plan.option_open_item`, `obs.option_open`, `master.option_list`, `master.option_contract` and their `.jp` forms; the reasons of the same dataset and key (subject = key) are joined in Go, the reason code is the run's own or else the first reason's, the detail is each reason's `scope: detail` joined by `; ` (cut to 200 runes); every reason of dataset `ops.not_wired` is a row `not_wired` with the job id as key and the NAME of the missing key as detail. The market is `jp` when the dataset id ends `.jp`, else `us`. `day` is the session day of the first listed run, else the UTC date of `now`. `notes` holds one line when the runs hold a finished run of `obs.option_eod` or `obs.option_eod_index` (built from the runs the page already reads, no other input): `Option chains stored today: US <n> names, <m> contracts; index <KEY> <u>, <KEY> <u> contracts; gaps: <list>.` from the newest finished run of each key (n the US keys, m their `Usable` sum, index keys sorted, `index: no run yet` without an index run; gaps are keys whose status is not `done` or whose `Usable` is 0, sorted, at most five then `and <k> more`); cut to 200 runes; `notes` is empty otherwise. Rows, `listed` and schema do not change. Imports no database package and no implementation package of `pages`; reads no store and no clock.
- `embed.Handler(viewModel) http.Handler` and `embed.Assets() http.Handler`: the package embeds `all:dist` (`internal/pages/embed/dist`, written by `pnpm --dir web build`, not committed; only `dist/.gitignore` is). `Handler` writes the view model into `dist/index.html`; `Assets` answers request paths `/assets/*` from `dist/assets`: another path, an unclean path or a missing file is 404, a method other than GET and HEAD is 405. When `index.html` is absent `Handler` answers 500 with the text `web bundle not built: run pnpm --dir web build` (no path in the body).
- `macro_page.NewPage(c)` returns `Meta{macro_page, page.macro_page.v1}` (v1 is written without a `Func`: `Config.Liquidity` nil); its `Build` uses a copy of `c` whose `Indicators` is copied at construction.
- `macro_page.Config` gains `Liquidity` (`liquidityapi.Func`), `LiquidityParams` (`liquidityapi.Params`) and `Net` (`liquidityapi.NetFunc`, put into `Input.Net`). With `Liquidity` nil the page writes exactly `page.macro_page.v1`, schema version 1, with no `liquidity` field and no series read for the block. With it, `NewPage` returns `Meta{macro_page, page.macro_page.v2}` and `Build` writes `schema_version` 2, `liquidity_title` ("Funding and credit background") and `liquidity`: it reads the fourteen series of `liquidityapi.Input` through the `store.SeriesReader` (the high-yield series from 2000-01-01, the others from 400 days before the day), calls `Liquidity` once and writes four sentences and four taps (`stlfsi`, `reserves_over_assets`, `discount_window`, `net_liquidity`) as English text with every figure's date. A figure with a `Reason` makes its sentence or row a gap (`no_input` to `no_data`; `missing_input`, `short_history`, `zero_range`, `bad_input` to `missing_input`; `stale_input` to `stale_input`), never a number; an error of a read is an error of `Build`. The page computes nothing: rounding for display is its only arithmetic. With `Liquidity` set the `sentence` is "Funding and credit background from stored series; events: no data yet." (without the last clause when `Events` is set).
- `home_macro.Config` gains `Series` (`store.SeriesReader`), `Liquidity` (`liquidityapi.Func`) and `LiquidityParams`. Only with `Liquidity` set, `card.say` is "Reserves $3.0tn, 4 weeks −$40bn (2026-11-11)." built from the `Reserves` and `Reserves4w` figures of the `Func` result over the WRESBAL series alone; with a nil `Series` or a figure with a `Reason` it is "Reserves: no data yet." and the card has a `no_data` gap. With `Liquidity` nil the `say` is the Ease sentence as before; `ease` is unchanged. The schema `page.macro_summary.v2` is unchanged.
- `market_page.Build(ctx, c Config, r store.SeriesReader, day, generatedAt)` and `market_page.NewPage(c Config)` (page name `market_page`, schema `page.market_page.v1`): `Config` is `RunID`, `BuildID`, `Scope`, `Zone` (`generated_at` is written in it) and `Readings`, a `compute.ReadingFunc`; a nil `Zone` or `Readings`, a nil series reader, a bad day or id is an error of `Build`, and so is a reader error (never a Gap).
- `market_state_page.Build(ctx, c Config, r store.SeriesReader, day, generatedAt)` and `market_state_page.NewPage(c Config)` (page name `market_state_page`, schema `page.market_state_page.v1`): `Config` is `RunID`, `BuildID`, `Scope`, `Zone`, `Readings` (`compute.ReadingFunc`), `Bars` (`bar.PriceBarReader`), `StockIDs` (an interface with `StockIDs(ctx, names)`), `Market` (`marketstateapi.Func`), `Liquidity` (`liquidityapi.Func`), `Figures`, `Units`, `Rules` (copied into `marketstateapi.Input`), `MarketParams`, `LiquidityParams` and `Symbols` (`[]Symbol{Symbol, Label, Group}`, group `sector` or `industry`; SMH is always a row). A nil `Market`, `Liquidity`, `Readings`, `Bars` or `StockIDs` gives the Gap `no_reader` on the rows that need it, never a number and never an error; a nil `Zone`, a nil series reader, a bad day or id, or a reader error is an error of `Build`. The page copies the figures of `Market` and `Liquidity` in the order given and sorts, ranks and computes none; its only arithmetic is decimal shifting and rounding (`math/big`). Bars are read for 140 calendar days before the day. `freshness_text` names the SPY last close day, says daily closes and not intraday, and names the FRED rows as daily series; `stale` is the oldest data day against the day with limit 4.
- Zone rule: no pages code names a zone; `macro_page.Config.Zone` is given by the caller.

## Inputs

- A `store.SeriesReader` (`SeriesPoints(ctx, seriesID, from, to)`), nothing else from `internal/store`.
- A `contracts.Day` (`YYYY-MM-DD`) and a `generatedAt` instant given by the caller; the builder reads no clock.
- `obs.series_point r1` rows, read for each of the seven series (`DGS10`, `DGS3MO`, `SP500`, `VIXCLS`, `VXNCLS`, `RVXCLS`, `VXVCLS`, in this order) from the day minus 30 calendar days to the day.
- For the handler, a view model as JSON bytes.

## Outputs

- `macro_rates.Build`: JSON of `contracts/schemas/page.macro_rates.v3.json` (`schema_version` 3; `index_points` text has two decimals and no suffix) (texts in English, written by `text.go`; `latest` is the last point or a gap); `generated_at` is `generatedAt` in UTC, `session_day` is the given day, points are in date order, a nil value is `null`.
- `gaps[]`: a nil value yields one `no_value` gap with the `series_id` and the date of the point. A series whose last point is more than 4 calendar days before the day, or that has no point in range, yields one `stale` gap with the day as `date`; a stale last point with a nil value gives that one gap only.
- `embed.Handler`: `text/html` with the view model in the vm element; `embed.Render` returns the page bytes or an error for a view model that is not JSON (the handler answers 500).
- `report_page.Build(ctx, c Config, day, generatedAt)` and `report_page.NewPage(c Config)` (page name `report_page`, schema `page.report_page.v2`): `Config` is `Market` (`US` or `JP`), `Slot` (`open` or `close`), `Zone` (`generated_at` is written in it) and `Risks`, a `RiskBlockFunc` (`func(ctx, day, generatedAt) ([]byte, error)`). The `risks` block is the bytes `Risks` returns, embedded unchanged; an error of `Risks`, a market or slot outside the lists, or a nil `Zone` or `Risks` is an error of `Build`. `actions`, `account_moves` and `market_watch` come from `Actions`, `AccountMoves` and `MarketWatch` of `Config` (each a `BlockFunc`, the shape of `RiskBlockFunc`) when non-nil, are never called for market `JP` (state `gap`, reason `jp_slice_missing`), and otherwise are gap-only: state `gap`, one `Gap` of reason `not_built`, each required figure field a `Gap` of reason `not_built`. `global_assets` comes from `GlobalAssets` of `Config` (a `BlockFunc`), which `Build` calls only for market `US` and slot `close`; a nil func, market `JP` and slot `open` keep the `not_built` gap block, and an error of the func is an error of `Build`. No optional block is written. The package computes no figure; only `ot` imports it.
- `market_page.Build` output: the weather headline and sentence from `market.sp500_vs_200d` (signed `percent`, `+3.12%`, half-even); `rank_3y` of SPX, NDX and RUT from the three percentile readings, unit `share_percent` (whole percent, `68%`, JSON number from the exact decimal text; N225 is a `no_data` Gap); the term cells from stored `VIXCLS` and `VXVCLS` points, unit `index_points` (two decimals; the ratio of `market.vix_term_ratio` in the term sentence has unit `ratio`, two decimals). `data_times` has one entry per series, `stale` is the oldest data day, `run_status` is `ok` or `partial` (never `failed`; permanent Gaps do not count) and the envelope `gaps` copy the Gap blocks in page order. The Gap blocks `weather.chart`, `breadth` and the N225 `iv`, N225 `rv20` and N225 `iv_minus_rv20` are `not_built`. The `iv` of SPX, NDX and RUT is the stored `market.iv_ibkr` and the `rv20` is the stored `market.rv20` (`underlying` subject), times 100 in `vol_points`, one decimal, half-even; a row without a reading is a `no_data` Gap, a reading not ok or negative is a `missing_input` Gap, a stored zero is the value `0.0`; neither Gap counts for `run_status`. The `iv_minus_rv20` of SPX, NDX and RUT is the stored `market.iv_rv20` (`underlying` subject), times 100 in `vol_points`, one decimal, half-even, signed in the text (`+3.2`, `-1.4`, `0.0`; the number has no plus) with no threshold or tone; when its `data_day` is not the page's day the text names it (`+3.2 (11-12)`). A stored `missing_input` with code 3, or a `data_day` more than 5 days before the page's day, is a `stale_input` Gap naming the day; another missing state or an ok reading without `data_day` is `missing_input`; no reading is `no_data`; none of them counts for `run_status`. Numbers are shifted and rounded half-even as decimal text (`math/big`), never as floats.

## Invariants

- The builder only formats stored values; it computes nothing, and a missing value is a gap, never 0.
- Staleness is date arithmetic on the two `YYYY-MM-DD` values; no calendar. The freshness limit (4) and the lookback (30) are package constants.
- The injected JSON is compacted and `<`, `>`, `&`, U+2028 and U+2029 are written as `\u` escapes, so a string value cannot close the script element; parsed, it equals the input.
- `dist/index.html` holds the vm element exactly once.

## Jobs and slots

None. The builder and the handler run in the commands that call them (`ot page`, `ot serve`, a follow-up design); they own no slot.

## Forbidden

- Importing pgx or a store implementation package from `internal/pages`.
- Computing a value, reading a clock or making a request in a page builder.
- Writing the view model into the page anywhere but the vm element, or without escaping.
- Editing `contracts/schemas` or `contracts/fixtures` from this package.
